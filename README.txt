DATE COUNTDOWN Android app
Version 1.0

Features:
- Choose target date and time
- Days / hours / minutes / seconds countdown
- Event name
- Saves countdown locally
- Reset
- Requests notification permission (notification scheduling can be added in a later version)

Build:
1. Open this folder in Android Studio.
2. Let Gradle sync.
3. Build > Build APK(s).
4. Install app-debug.apk on your Android phone.

Package: com.roshan.datecountdown
